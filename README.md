# UNO - Juego de Cartas

Implementación digital del clásico juego de cartas UNO, desarrollado completamente en Java utilizando Programación Orientada a Objetos (POO) y una interfaz gráfica interactiva.

## Características
* **Lógica Completa:** Gestión del mazo oficial de cartas, incluyendo cartas de acción (Reversa, Salto), comodines y cartas +4/+2.
* **Carga Dinámica de Recursos:** Implementación de algoritmos con expresiones regulares (`Regex`) para leer y clasificar automáticamente los atributos de las cartas (color y número) a partir de los archivos de imagen locales.
* **Interfaz Gráfica (GUI):** Interfaz amigable y visual desarrollada con la biblioteca Java Swing (JFrame/JPanel).

## Tecnologías Utilizadas
* **Lenguaje:** Java
* **Interfaz:** Java Swing / AWT
* **Entorno de Desarrollo (IDE):** Apache NetBeans
